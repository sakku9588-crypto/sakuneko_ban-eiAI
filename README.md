# sakuneko_ban-eiAI
🐎 Sakuneko Ban'ei AI v15.1
Developed by Sakku at Sakuramori Lab, this tool is a specialized AI for Ban'ei Keiba (Draft Horse Racing). It moves beyond simple statistics, incorporating hurdle clearance ability, weight fluctuations, and professional jockey scoring.
🐱 Overview
Ban'ei racing is unique—it's not just about speed, but power and strategy. This AI evaluates horses based on a complex weighting system that mimics the decision-making of professional bettors.
🛠️ Key Features
• Sophisticated Weighting System:
• Obstacle Ability (35%): The most critical factor in Ban'ei.
• Jockey Skill (12%): Scoring based on top-tier professional performance.
• Triple Rate Logic (15%): Equal weights for Win, Place, and Show rates.
• Weight Dynamics (8%): Analyzes the impact of weight changes relative to previous races.
• 🆚 Head-to-Head Mode: Directly compare two horses to determine the superior contender with a detailed score breakdown.
• 🎲 Random Race Simulation: A debugging tool that generates a full field of horses to test the AI's logic instantly.
• Autocomplete Horse Database: Built-in dictionary of historical Ban'ei horses for fast data entry.
